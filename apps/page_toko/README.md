# RideOn - Mitra Toko

![RideOn](assets/logo-new.png)

Aplikasi Mitra Toko (Merchant) untuk platform RideOn. Dibuat menggunakan Flutter.

## Modul yang Tersedia:
- **Autentikasi & Registrasi**: Pendaftaran pemilik toko, data usaha, OTP WhatsApp.
- **Home / Beranda**: Ringkasan omzet, status buka/tutup toko, pesanan aktif.
- **Pesanan**: Filter status pesanan, rincian item, estimasi waktu masak, kontak kurir.
- **Menu**: Manajemen katalog menu, ketersediaan stok, tambah & ubah menu.
- **Keuangan**: Saldo aktif toko, tarik saldo, rekening bank tujuan, verifikasi PIN.
- **Profil Toko**: Pengaturan identitas toko, jam operasional, titik lokasi toko.
